# Syed Nihaal Shah | IT Portfolio

A responsive personal portfolio website built for the **Cloud Computing** additional activity (SENG-611) at the University of Sindh, Jamshoro. It presents my profile, education, skills, projects, experience and contact details in one clean page.

**Live website:** https://syed-nihaal-shah-portfolio.vercel.app/
**GitHub repository:** https://github.com/nehaal-shah/portfolio

## About the project

I am a 3rd year BS Information Technology student at the University of Sindh, Jamshoro, with a core interest in copywriting, social media marketing and web development. This portfolio is a single-page site that works on desktop, tablet and mobile.

## Sections

1. Home / Hero
2. About Me
3. Career Objective
4. Education
5. Technical Skills
6. Projects
7. Case Study (upcoming research collaboration)
8. Experience and Training
9. Certifications and Courses
10. Achievements and Awards
11. Resume / CV (view and download)
12. GitHub and Professional Profiles
13. Contact
14. Navigation and Footer

## Features

- Sticky navigation bar with links to every section and highlighting of the current section
- Responsive layout with a mobile menu
- Accessible markup: skip link, alt text, logical heading order, visible keyboard focus, readable contrast
- Contact form that opens the visitor's email app (no backend, no secrets)
- CV available to view and download as a PDF

## Tech stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript
- Google Fonts: Cormorant Garamond and Manrope
- Hosting: Vercel / Netlify, connected to this GitHub repository

## Deployment

The site is deployed through the Git integration of Vercel / Netlify:

1. Push the project to a public GitHub repository.
2. In Vercel or Netlify, choose **Import from Git** and select this repository.
3. Framework preset: **Other**, no build command, publish directory: `.` (root).
4. Deploy. Every new commit pushed to the main branch redeploys the site automatically.

## Customising

- Edit the text in `index.html`.
- Colours are CSS variables at the top of `style.css`.
- Replace `assets/pfp.jpg` and `assets/cv.pdf` with updated files.
