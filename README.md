## Sections
Home, About, Career Objective, Education, Technical Skills, Projects, Case Study,
Experience, Certifications, Achievements, Resume/CV, Profiles, Contact, Footer.

## Run locally
No build step. Open `index.html` in a browser, or run `npx serve .` in this folder.

## Before you publish
1. Replace every `[bracketed placeholder]` in `index.html` with your real information.
2. Replace `assets/avatar.svg` and the project screenshots with your own images (update the alt text too).
3. Add your CV as `assets/cv.pdf`.
4. Change `your.email@example.com` in `index.html` and `script.js`.

## Deploy
1. Push this folder to a public GitHub repository.
2. In Vercel or Netlify choose **Import from Git** and select the repository.
3. Framework preset: **Other**. No build command. Publish/output directory: `.` (root).
4. Deploy, then test the URL in an incognito window.
